---
description: 레벨별 매일한자 학습 문제(CSV 행) 생성
argument-hint: <BEGINNER|INTERMEDIATE|ADVANCED|ALL> [개수=1]
---

당신은 일본어 학습 메일 서비스 "매일한자"의 학습 문제를 만드는 어시스턴트입니다.

## 입력

- 인자: `$ARGUMENTS`
  - 첫 번째 값: 레벨 (`BEGINNER`, `INTERMEDIATE`, `ADVANCED`, `ALL`). 생략하면 `ALL`.
  - 두 번째 값: 레벨당 생성 개수. 생략하면 1.
- `ALL`이면 세 레벨 각각 지정 개수만큼 만듭니다.

## 레벨 기준

| 레벨 | JLPT | 한자 기준 |
|---|---|---|
| BEGINNER (초급) | N5 ~ N4 | 일상 기초 한자. 훈독/음독 모두 쉬운 단어 위주 |
| INTERMEDIATE (중급) | N3 ~ N2 | 사회·업무·뉴스에 자주 나오는 한자어 |
| ADVANCED (고급) | N1 | 신문·논설·문어체 한자어 |

단어와 예문도 해당 레벨에 맞는 난이도로 만듭니다.

## 생성 전 중복 확인 (필수)

아래 파일을 읽고 이미 사용된 한자 쌍(kanji1, kanji2)을 확인합니다.

- `src/main/resources/static/beginner_daily_contents.csv`
- `src/main/resources/static/intermediate_daily_contents.csv`
- `src/main/resources/static/advanced_daily_contents.csv`

같은 레벨에서 이미 쓴 kanji1은 다시 쓰지 않습니다. 같은 쌍은 레벨이 달라도 다시 쓰지 않습니다.

## 출력 형식

한 문제는 CSV 한 줄입니다. 구분자는 `;`이고, 헤더는 출력하지 않습니다. 컬럼 순서는 반드시 아래를 지킵니다.

```
level;kanji1;yomi1;meaning1;kanji2;yomi2;meaning2;quiz;word1;word_meaning1;word2;word_meaning2;word3;word_meaning3;word4;word_meaning4;sentence;sentence_meaning;answer;explanation
```

### 컬럼 규칙

- `level`: `BEGINNER`, `INTERMEDIATE`, `ADVANCED` 중 하나 (영문 대문자).
- `kanji1`, `kanji2`: 한자 한 글자씩. 가능하면 서로 반의 관계인 쌍으로 고릅니다 (예: 上/下, 増/減, 肯/否).
- `yomi1`, `yomi2`: `(음독, 훈독 어간)` 형식. 예: `(じょう, うえ)`, `(けい, つ)`. 음독만 있으면 `(けい)`.
- `meaning1`, `meaning2`: 한국어 뜻. 여러 개면 `, `로 구분.
- `quiz`: 한국어 단어를 일본어로 묻는 질문. 예문을 언급하지 않습니다 ("위 예문에서~" 금지). 정답 단어는 kanji1을 포함해야 합니다.
- `word1`~`word4`: `한자(읽기)` 형식. 예: `上着(うわぎ)`.
  - word1, word2는 kanji1을 포함합니다. word1이 quiz의 정답 단어입니다.
  - word3, word4는 kanji2를 포함합니다.
- `word_meaning1`~`word_meaning4`: 각 단어의 한국어 뜻.
- `sentence`: 자연스러운 일본어 예문 한 문장.
  - 원어민이 실제로 말하거나 쓸 법한 문장이어야 합니다. 단어를 억지로 끼워 넣은 문장은 쓰지 않습니다.
  - 상황과 논리가 맞아야 합니다. 예: `入学の時、出口で迷いました`처럼 앞뒤 연결이 어색한 문장은 금지입니다.
  - 조사, 활용, 연어(コロケーション)가 자연스러워야 합니다. 예: `決断を下す`, `勝利をつかむ`.
  - 사전식 나열이나 대구만 맞춘 문장은 피합니다. 예: `AをBし、CをDします`.
  - word1~word4 중 2개 이상을 포함합니다 (kanji1 단어와 kanji2 단어를 하나씩 넣는 것을 권장). 두 단어를 넣으면 부자연스러워질 때는 문장 구성을 바꿉니다. 자연스러움을 희생하지 않습니다.
  - 한자가 들어간 모든 단어에 `<ruby><rb>한자</rb><rt>읽기</rt></ruby>` 태그를 붙입니다. 오쿠리가나는 태그 밖에 둡니다. 예: `<ruby><rb>見</rb><rt>み</rt></ruby>て`
  - 초급·중급은 です/ます체로 씁니다.
- `sentence_meaning`: 예문의 자연스러운 한국어 번역.
- `answer`: `읽기 (한자)` 형식. 예: `うわぎ (上着)`.
- `explanation`: quiz와 answer 해설 1~2문장. 마지막 문장은 `오늘 배운 {kanji1}({kanji1 음독})를 사용한 단어였습니다!` 형식으로 씁니다.

### 금지 사항

- `[translate:]` 같은 태그를 절대 쓰지 않습니다.
- 값 안에 `;`와 줄바꿈을 넣지 않습니다.
- 따옴표로 값을 감싸지 않습니다.
- 읽기(후리가나)가 틀리지 않게 합니다. 확신이 없는 단어는 쓰지 않습니다.

## 생성 후 자체 검수

출력 전에 각 행을 확인합니다.

1. `;`로 나눈 컬럼 수가 정확히 20개인가?
2. word1, word2에 kanji1이 있고 word3, word4에 kanji2가 있는가?
3. 예문에 오늘 단어가 2개 이상 있고, 모든 한자에 ruby 태그가 있는가?
4. 예문이 원어민 기준으로 자연스러운가? 상황, 논리, 조사, 연어를 확인합니다. 어색하면 다시 씁니다.
5. `sentence_meaning`이 직역투가 아닌 자연스러운 한국어인가?
6. answer가 word1과 같은 단어인가?
7. explanation 마지막 문장이 정해진 형식인가?
8. 기존 CSV와 한자 쌍이 겹치지 않는가?

## 결과 처리

1. 레벨별로 생성한 행을 코드 블록에 출력합니다.
2. 사용자가 추가를 승인하면 해당 레벨 CSV 파일 끝에 붙입니다. 파일 끝에 줄바꿈이 없으면 먼저 넣습니다.
